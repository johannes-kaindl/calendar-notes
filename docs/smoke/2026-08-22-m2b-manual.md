## Schritte

1. **Vault öffnen.** Obsidian → „Open folder as vault" → den Staging-Vault-Pfad oben wählen.
2. **Plugin prüfen.** Einstellungen → Community-Plugins: „Calendar & Contact Notes" sollte
   bereits aktiv sein (per `community-plugins.json` vorbelegt); falls nicht, manuell einschalten.
3. **Konto anlegen.** Plugin-Einstellungen öffnen → „Konten" → „Konto hinzufügen":
   - Name: `Radicale Test`
   - Server-URL: `http://127.0.0.1:5232/`
   - Benutzername: `test`
   - Passwort: `test` (Secret-Feld)
4. **Verbindung testen.** Button „Verbindung testen & Sammlungen finden" — erwartet:
   Notice „2 Sammlung(en) gefunden (0 Warnung(en))" (1 Kalender + 1 Adressbuch).
5. **Sammlungen aktivieren.** Unter „Sammlungen" → Konto „Radicale Test" öffnen → für
   Kalender „kalender" und Adressbuch „kontakte" jeweils „Spiegeln" einschalten. Profile
   bleiben auf den Standard-Profilen (`default-event` / `default-contact`).
6. **Vorschau.** „Aktionen" → „Vorschau (Trockenlauf)" — erwartet: Modal mit
   „Vorschau — 5 Änderung(en)" (3 Termin-Notizen + 2 Kontakt-Notizen, alle „Neu anlegen"),
   keine Fehler, keine Hand-Edits.
7. **Ausführen.** Im Vorschau-Modal „Jetzt ausführen" — erwartet: Notizen erscheinen unter
   `Events/` (3 Stück) und `Contacts/` (2 Stück) mit befülltem Frontmatter
   (`dav_uid`, `dav_source`, `dav_etag`, Termin-/Kontaktfeldern).
8. **Zweiter Lauf.** Kommandopalette → „Alle Sammlungen synchronisieren" (oder Button
   „Jetzt synchronisieren" je Sammlung) — erwartet: keine neuen/aktualisierten Notizen
   (alle Objekte unverändert, `dav_etag` stimmt noch), Status-Zeile zeigt „0 neu, 0
   aktualisiert, 0 archiviert, 0 gelöscht, 0 Fehler."
9. **Kommandopalette stichprobenhaft.** `Cmd/Ctrl+P` → „Eine Sammlung synchronisieren…" öffnet einen
   Fuzzy-Suggester über die beiden aktivierten Sammlungen; Auswahl synchronisiert nur diese.

## Später gegen Pallas (echtes Vault)

Vor dem produktiven Einsatz **immer erst „Vorschau (Trockenlauf)"** fahren, bevor
„Jetzt ausführen" oder eine echte Sync-Intervall-Konfiguration aktiviert wird — Pallas
enthält reale Notizen, ein Fehlgriff bei Ordner-/Profilzuordnung soll dort auffallen,
bevor er schreibt. Konto mit den echten Server-Zugangsdaten anlegen, Discovery laufen
lassen, Sammlungen bewusst einzeln aktivieren (nicht alle auf einmal), pro Sammlung
zuerst die Vorschau lesen. Erst wenn die Vorschau plausibel aussieht (richtige Anzahl,
richtige Ordner, keine unerwarteten Löschungen), „Jetzt ausführen" antippen.
